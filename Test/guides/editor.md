# Editor

The editor lists the Markdown files under your docs root.

## Save a change

1. Select a file.
2. Edit the Markdown. The preview updates beside the editor.
3. Click **Save**. The file is committed to the branch you chose.

> [!TIP]
> If GitHub has a newer copy, the editor asks you to reload instead of overwriting it.

## Pages

Each page is one `.md` file. The sidebar title comes from the first heading.
