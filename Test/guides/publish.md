# Publish

The public site reads the repository. A saved file is the published file.

## Address

Your site lives at the project slug, for example `/your-slug/guides/quickstart`.

## Search

Search looks through the indexed text of each page. New and edited pages are indexed when you save, and again when GitHub sends a push.

## Assistant

Ask AI stays off until `AI_API_KEY` is set. The rest of the site still publishes without it.
