# Welcome to Test-sews-docs

This is the starter site created with your project. Change it in the editor, then save. The save becomes a commit on your selected branch.

## What you can do

- Write guides in Markdown.
- Organize pages from `docs.json`.
- Search the published site.
- Ask questions once an AI key is configured.

> [!NOTE]
> This page is a starting point. Replace it with your own product guide.

## Create a page

1. Open the editor.
2. Add a file such as `guides/install.md`.
3. List that page in `docs.json`.
4. Save. The public site updates from the repository.
